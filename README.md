# 📘 Facebook Clone Website

A frontend **Facebook website clone** created as part of my learning journey in **HTML, CSS, Git, and GitHub**.

This project recreates the basic visual structure and user interface of Facebook using frontend technologies. The main purpose of this project is educational — to practice website development, understand how web pages are structured, and learn how to manage and publish code using Git and GitHub.

---

## 📌 Project Overview

The **Facebook Clone Website** is a frontend-based web development project inspired by the general layout and design of Facebook.

The project focuses on creating a familiar social-media-style interface using **HTML and CSS**. It includes different sections of a typical social media website such as navigation, profile information, posts, sidebar elements, and other UI components.

This project was developed while following a **Git and GitHub tutorial**, which helped me understand both frontend development and version control.

The project also serves as a foundation for future improvements where interactive functionality can be added using JavaScript and backend technologies.

## 🔧 Git Commands Practiced

During the project, some of the fundamental Git commands that can be practiced include:

### Initialize Git

```bash
git init
```

Initializes a Git repository inside the project folder.

### Check Repository Status

```bash
git status
```

Shows the current status of files and changes.

### Add Files

```bash
git add .
```

Stages the project files for the next commit.

### Create a Commit

```bash
git commit -m "Initial commit"
```

Creates a snapshot of the current project with a message.

### Connect GitHub Repository

```bash
git remote add origin <repository-url>
```

Connects the local Git repository to the GitHub repository.

### Push Code

```bash
git push -u origin main
```

Uploads the local project to GitHub.

### Pull Updates

```bash
git pull
```

Downloads and integrates changes from the remote repository.

## 🚀 How to Run the Project

### Method 1 — Open Directly

1. Download or clone the repository.
2. Open the project folder.
3. Locate `index.html`.
4. Double-click the file.
5. The website will open in your default browser.

### Method 2 — Using VS Code

1. Open **Visual Studio Code**.
2. Select **File → Open Folder**.
3. Select the `fb-clone-website` folder.
4. Open `index.html`.
5. Run the webpage using your preferred browser or a development extension such as Live Server.
